# Web Admin 管理中心

```bash
uv run python main.py
```

启动后访问：

```text
http://127.0.0.1:8001
```

界面右上角可切换「浅色 / 深色」皮肤，选择会保存在浏览器本地；首次打开时跟随系统配色。

## 任务台

任务台分三栏：会话、任务列表、任务详情，下方是「任务窗口」。

- 任务列表每行右侧有一个「更多操作」三点按钮，点开后是菜单：复制提示词、编辑、重新执行、Fork 新会话、撤销改动、删除。
  - 「复制提示词」把该任务的原始提示词写入剪贴板；复制成功后菜单项会短暂显示「已复制」。
  - 「Fork 新会话」把该任务和它之前的所有任务复制到一个新会话，并切到那个会话；原会话保持不变，会话名取自分叉的任务。
  - 「重新执行」先撤销并删除原任务，同时删除它在同一会话中之后的所有任务，再用同样的内容跑一遍。重跑出来的是会话的最后一轮，它之后的任务不会作为上下文保留；会话只有这一个任务时，重跑前的历史消息即为空。
  - 「编辑」把该任务的提示词、智能体、模型回填到任务窗口；再次发送时**替换**原任务：先撤销并删除原任务，再删除它在同一会话中之后的所有任务，然后用编辑后的内容重新执行。
  - 两者都会丢弃之后的任务，所以适合从一个较早的任务重新往下走；只想删任务不重跑时用「删除」。
- 正在运行的任务不能编辑或重新执行，先停止它；如果它之后还有正在运行的任务，「重新执行」和「编辑」会先停止那些任务再删除。

## 参数说明（关键）

```text
--host HOST          监听地址（默认 127.0.0.1）
--port PORT          监听端口（默认 8001）
--reload             运行时热重载
```
