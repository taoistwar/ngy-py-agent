# Web Admin 管理中心

```bash
uv run python main.py --web
```

启动后访问：

```text
http://127.0.0.1:8001
```

界面右上角可切换「浅色 / 深色」皮肤，选择会保存在浏览器本地；首次打开时跟随系统配色。

## 任务台

任务台分三栏：会话、任务列表、任务详情，下方是「任务窗口」。

- 任务列表每行右侧有五个按钮：编辑、重新执行、Fork 新会话、撤销改动、删除。
  - 「Fork 新会话」把该任务和它之前的所有任务复制到一个新会话，并切到那个会话；原会话保持不变，会话名取自分叉的任务。
  - 「重新执行」先撤销并删除原任务，再用同样的内容跑一遍。
  - 「编辑」把该任务的提示词、智能体、模型回填到任务窗口；再次发送时**替换**原任务：先撤销并删除原任务，再删除它在同一会话中之后的所有任务，然后用编辑后的内容重新执行。
  - 之后的任务不会作为上下文保留，所以「编辑」适合改一个早期的任务再往下走；只想重跑最后一轮用「重新执行」即可。
- 正在运行的任务不能编辑或重新执行，先停止它。

## 参数说明（关键）

```text
--web
--host HOST          监听地址（默认 127.0.0.1）
--port PORT          监听端口（默认 8001）
--reload             运行时热重载
```
