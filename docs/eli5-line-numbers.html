为什么要给每一行编个号？

就像书要有页码。查东西的时候靠它，读故事的时候它是累赘。

需要它的时候

1|
2|
3|
4|

“把第 3 行改掉。”

有号码，一眼就找到那一行。

不需要它的时候

“这文件讲了啥？”

只要内容，号码用不上，还白占地方。

所以答案

  • 要指位置（改代码、说“第几行有问题”）→ 必须有。
  • 只要内容（总结、翻译、找关键词）→ 纯浪费。
  • 浪费多少？读 2000 行，号码大约多花 4000 个 token。
  • 不知道对方要干嘛的时候，默认带上更安全——少个号码会让人数错行，多个号码只是花点小钱。

加个开关吗？

建议加。用 include_line_numbers，默认 true：

  • include_line_numbers: true → 3| 内容
  • include_line_numbers: false → 内容（省 token）
